5. LOGIN DE CASETA (IMPLEMENTAR EXACTAMENTE ASÍ)
---------------------------------------------------------------------
Guard / modelo:
  La sesión de Caseta SIEMPRE autentica un registro de usuarios_caseta.
  Así Auth::user()->id sigue siendo el guardia_id de siempre.
  - Caseta en su propio proyecto: su App\Models\User con
      protected $table = 'usuarios_caseta';
    y agregar 'user_id' a $fillable y una relación de solo lectura a la
    tabla users de RH (modelo propio, p. ej. EmpleadoRh con
    $table = 'users', SoftDeletes, sin escribir nunca).
  - Si se integra dentro de la app RH: modelo UsuarioCaseta + guard
    `caseta` + provider propio. NO tocar el guard `web` de RH.

NO usar Auth::attempt() para los vinculados: la contraseña está en otra
tabla. Validar a mano y luego Auth::login($perfil).

Algoritmo (en este orden). Formulario: correo + contraseña. Mantener throttle.

  $correo = mb_strtolower(trim($request->email));

  PASO 1 - ¿Es una persona de RH?
    Si el correo es de relleno -> saltar al PASO 2.
    $empleado = users WHERE LOWER(TRIM(email)) = $correo AND deleted_at IS NULL
    Si existe:
      a) Hash::check($password, $empleado->password)  si no -> error genérico
      b) tiene 'intercambios' activo en sistema_usuario  si no ->
         "No tienes acceso a este sistema."
      c) must_change_password == 1                   si sí ->
         "Debes cambiar tu contraseña en la app de RH antes de entrar."
         (pasa cuando un admin de RH le resetea la contraseña o es empleado
         nuevo con contraseña inicial)
      d) $perfil = usuarios_caseta WHERE user_id = $empleado->id
         Si no existe -> CREARLO (alta automática):
           user_id = $empleado->id, email = $correo,
           name = nombre completo de info_usuarios, rol = 'caseta',
           activo = 1, password = Hash::make(Str::random(64))
         Si existe y su email no coincide con $correo -> actualizar
           usuarios_caseta.email = $correo (RH es la fuente del correo).
      e) $perfil->activo == 1                        si no -> "Cuenta desactivada."
      f) Auth::login($perfil, $remember); regenerar sesión.
      FIN.

  PASO 2 - ¿Es una cuenta genérica?
    $perfil = usuarios_caseta WHERE email = $correo AND user_id IS NULL
    Si existe, Hash::check contra usuarios_caseta.password y activo = 1;
    si pasa, Auth::login($perfil). FIN.

  PASO 3 - Nada coincide -> error genérico.

  Error genérico (1a, 2 y 3): el MISMO mensaje, p. ej.
  "El correo o la contraseña no coinciden.", para no revelar qué correos
  existen.

  Regla de oro: un perfil CON user_id nunca entra por el PASO 2. Su
  contraseña local no se usa.

Revalidación en cada petición (middleware, p. ej. VerificarAccesoCaseta,
en todas las rutas autenticadas):
  Si Auth::user()->user_id no es NULL, comprobar que:
    - el users sigue activo (deleted_at IS NULL),
    - sigue con 'intercambios' en sistema_usuario,
    - must_change_password = 0, y
    - la contraseña no cambió desde que inició sesión: guardar en sesión
      hash('sha256', users.password) al hacer login y comparar. Si cambió
      (la cambiaron en RH), cerrar la sesión.
  Si falla algo: Auth::logout(), invalidar sesión, regenerar token y mandar
  al login con el mensaje correspondiente.
  Consulta de ejemplo:
    $emp = DB::table('users')->where('id', $perfil->user_id)->whereNull('deleted_at')->first();
    $ok = $emp && !$emp->must_change_password
       && hash('sha256', $emp->password) === session('caseta_pwd')
       && DB::table('sistema_usuario as su')
            ->join('sistemas as s', 's.id', '=', 'su.sistema_id')
            ->where('su.user_id', $emp->id)
            ->where('s.clave', 'intercambios')->where('s.activo', true)
            ->exists();

"Recordarme" (remember_token): está en usuarios_caseta; funciona igual. El
middleware de arriba corta la sesión aunque venga de la cookie de recordar.

Nombre mostrado y guardia_nombre:
  - Vinculado: nombre completo desde info_usuarios.
  - Genérica: usuarios_caseta.name.
  Los nombres ya guardados en intercambios/bitácoras son históricos: no tocarlos.
